# Section 179D Commercial Building Tax Deduction

Quantify and document energy-efficiency deductions for qualifying commercial building systems and government-project allocations.

**Primary buyer:** Commercial building owners and designers. **Evidence:** building ownership, construction costs, energy models, lighting, HVAC, envelope systems, placed-in-service dates, allocation letters, certifications, and returns.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Building project registry
- Ownership eligibility
- Government allocation control
- Construction cost ingestion
- Lighting system evidence
- HVAC system evidence
- Envelope system evidence
- Energy model validation
- Reference standard mapping
- Efficiency threshold calculation
- Placed-in-service validation
- Deduction calculation
- Certification evidence
- Return workpaper generation
- Building tax analytics

Run `./start.sh`, then open <http://127.0.0.1:4681>. API: `5681`.
